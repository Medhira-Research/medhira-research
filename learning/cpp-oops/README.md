# C++ with OOP — Medhira Research

A practical, exercise-first learning track for C++ and Object-Oriented Programming, added as a separate Medhira learning path alongside Python.

## Goal

Build a strong foundation in C++ and OOP for semester coursework, problem solving, and future systems/backend projects.

## How to learn

1. Understand the concept before coding.
2. Type the examples yourself.
3. Compile and run every program.
4. Read compiler errors instead of ignoring them.
5. Solve small exercises before moving to the next concept.
6. Keep programs small and focused.
7. Commit meaningful progress when work is stable.

## Rules

- Understand before moving on.
- Compile and run code yourself.
- Be able to explain every line you submit.
- Prefer small working programs.
- Do not copy solutions without understanding them.
- Keep coursework and personal projects clearly separated.
