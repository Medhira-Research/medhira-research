# Daily Python Problem Solving

One small programming problem per day, alongside the Python-from-zero lessons.

## Platforms

- HackerRank — beginner-friendly structured practice
- LeetCode — problem-solving and interview-style practice
- CodeChef — competitive programming and implementation practice
- Codeforces — competitive programming and algorithmic problem solving

## Rule

Start with **1 problem per day**. The goal is consistency, not grinding.

### Daily workflow

1. Read the problem carefully.
2. Try to solve it yourself before asking for help.
3. Write the solution in Python.
4. Test it with sample and edge cases.
5. Submit it on the platform.
6. If it fails, debug the code and understand why.
7. Record the problem, platform, topic, result, and what you learned.

## Platform rotation

Rotate platforms rather than trying to do everything at once:

**HackerRank → LeetCode → CodeChef → Codeforces → repeat**

Difficulty should increase slowly. During the Python foundations stage, prefer basic problems involving output, variables, arithmetic, strings, conditions, and loops.

## Important

Do not jump into difficult competitive-programming problems just to maintain a streak. The daily problem should reinforce whatever Python concept you are currently learning.

AI can explain a problem, give hints, review your approach, or help debug after you have tried. The final solution should be understandable enough for you to explain line by line.
