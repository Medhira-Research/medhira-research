# Medhira Research

**Independent Student-Led Research & Learning Collective**

> Exploring intelligence. Engineering evidence.

Medhira Research is an independent student-led initiative and community space for learning technology, building practical projects, exploring research, and connecting with curious students.

We welcome beginners who are still figuring out computers, coding, GitHub, Linux, research, or their first direction in tech.

## Focus Areas

- AI & Machine Learning
- Computer Vision & Image Forensics
- Cloud & Backend Engineering
- Linux, Open Source & Developer Tools
- Beginner-friendly technology education
- Research communication and reproducible experimentation

## Learning Paths

The website includes beginner guides and learning roadmaps covering:

- Computer basics
- Python
- Web development
- Git & GitHub
- Linux & the terminal
- AI/ML
- Cloud & DevOps
- Research fundamentals

## Repository Structure

- `website/` — static website
- `website/data/` — guides, roadmaps, projects, and people data
- `docs/` — mission and governance documents
- `community/` — beginner pathways and community notes
- `research-template/` — starter structure for research projects
- `opportunities/` — opportunity-tracking templates

## Community Values

Curiosity, experimentation, friendly collaboration, respectful banter, clear documentation, ethical data handling, and contribution-based credit matter here.

You can learn, ask basic questions, share resources, collaborate, and connect in the language that feels comfortable to you—as long as everyone is treated with respect.

## Contributing

Read `docs/GOVERNANCE.md` and `community/GETTING_STARTED.md` before contributing. Contributions can include documentation improvements, beginner explanations, reliable resources, tutorials, code, and constructive feedback.

## Independence

Medhira Research is an independent student-led initiative. It is not a university department, placement agency, or guarantee of internships, jobs, funding, mentorship, or publication.
