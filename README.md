# Medhira Research

**Independent Student-Led Research Collective**

> Exploring intelligence. Engineering evidence.

Medhira Research is an independent student-led collective focused on practical, reproducible research and engineering in:

- AI & Machine Learning
- Computer Vision & Image Forensics
- Cloud & Backend Engineering

## Divisions

- **Intelligence Lab** — machine learning, AI systems, and experimentation
- **Vision & Forensics Lab** — computer vision, scientific image analysis, and image forensics
- **Systems Lab** — backend engineering, cloud infrastructure, and developer tooling

## Flagship Focus

Our initial research direction is **scientific image forensics**, including microscopy-image analysis and the detection of AI-generated or steganographically manipulated images.

## Repository Structure

- `website/` — static website
- `docs/` — mission and governance documents
- `research-template/` — starter structure for research projects
- `opportunities/` — curated opportunities tracker
- `.github/profile/` — profile README content

## Contributing

We value reproducibility, clear documentation, ethical data handling, and contribution-based credit. Read `docs/GOVERNANCE.md` before contributing.

## Independence

Medhira Research is an independent student initiative. It is not a university department, placement agency, or guarantee of internships, jobs, funding, or publication.
